# 渠道管理使用手册

## 模块简介
本模块为运营人员提供统一的多渠道接入与客户互动管理能力。系统支持微信公众号、小程序及企业微信等主流社交平台的账号集中配置与连接状态监控，解决多平台消息收发配置分散、客户来源难以追踪的问题。通过活码分流体系、自动化消息触达、智能文案辅助及菜单统一管理等功能，帮助运营团队高效沉淀私域流量、优化引流路径并提升用户交互体验。

## 核心功能
### 渠道接入与连接管理
支持多类型社交渠道的账号信息录入与生命周期管理。运营可完成渠道的新增、编辑、查询与停用操作，并通过系统内置的连接测试接口验证通道连通性。模块内置回调签名验证与消息解密机制，确保外部消息能够安全、准确地路由至内部处理流程。

### 活码管理与扫码数据分析
提供渠道码、门店码与员工码三类活码的创建与维护能力。系统支持轮询分配策略与自动轮转机制，可根据业务负载灵活切换目标接收方。针对门店场景，支持基于地理位置解析最近门店并绑定对应活码。所有活码均完整记录扫码行为，提供扫码明细统计、转化率计算、排名查询及过期清理功能，为引流效果评估提供数据支撑。

### 自动化消息与AI增强触达
涵盖欢迎语、模板消息与智能回复三大核心场景。运营可自定义欢迎语文本与多媒体素材，配置标准化模板消息格式并进行发送测试。结合AI增强服务，系统支持欢迎语与菜单文案的智能生成、用户消息意图识别路由以及自动化回复策略，大幅降低人工编辑成本，提升即时响应效率。

### 微信菜单配置与发布
提供公众号底部菜单的结构化配置能力。运营可在后台编排菜单层级、按钮名称与跳转动作，保存草稿后一键发布至微信平台，实现对外展示内容的统一管控与快速迭代。

## 常见操作流程
### 新增与配置渠道账号
1. 登录控制台，进入「渠道管理」列表页，点击新建渠道入口。
2. 填写渠道名称、平台类型及相关身份凭证信息。
3. 保存基础配置后，调用 `POST /channels/{id}/test` 接口验证网络连通性与凭证有效性。
4. 渠道详情页「回调配置」自动展示权威回调 URL（`GET /channels/{id}/callback-info`），复制后在对应第三方平台完成回调地址与加密密钥备案。**回调域名与租户自定义域名联动**：租户已启用完全自定义域名（approved）时回调 URL 使用租户自有域名（微信/企微回调域主体校验要求）；未启用时使用平台统一回调域；页面按状态给出前置要求提示。

### 创建与分发活码
1. 进入控制台「活码管理」页面，选择目标类型（渠道码/门店码/员工码）并新建活码。
2. 配置跳转目标链接、关联渠道及有效期参数。
3. 保存后进入详情页查看实时扫码统计与转化数据，按需调整分配策略。
4. 业务周期结束后，执行删除或过期处理以释放资源。

### 配置欢迎语与模板消息
1. 进入「欢迎语」管理页，新建消息条目，编写触发内容并上传配套素材，设置生效状态。
2. 进入「模板消息」管理页，保存所需的消息模板结构与变量占位符。
3. 使用 `POST /wechat/templates/send-test` 接口验证模板渲染效果，确认排版与变量替换无误后投入实际业务场景。

### 编排与发布微信菜单
1. 进入「微信菜单」配置页，根据品牌规范与业务引导需求编排菜单层级。
2. 保存菜单结构草稿，核对按钮动作与链接指向。
3. 执行 `POST /wechat/menus/publish` 接口操作，使新菜单结构正式同步至微信客户端。

## 相关配置说明
渠道配置需严格核对各平台的身份标识与密钥参数，确保回调通信链路畅通。活码配置中需注意类型选择与目标链接的业务匹配关系，门店码将自动启用地理位置解析逻辑以实现就近分配。欢迎语与模板消息均支持多素材组合与状态控制，运营可根据实际交互节点调整内容格式。所有配置变更将在保存或发布后立即写入数据库，系统自动记录操作时间与状态流转，便于后续审计与回溯。
